# **Platformer Video Game - Unity (Project for Practice)**

## **Project Overview**  
This project is a **platformer video game** developed as part of my coursework to practice **Unity** game development. It was my first development project in Unity, where I applied fundamental game mechanics and learned essential game development concepts. The game features multiple characters, but all follow a single main character. It includes enemies with varying difficulty levels, and a **turn-based battle system** where enemies randomly attack the player characters. The attacks are determined through an algorithm that emulates dice rolls, adding an element of chance to each encounter.

Additionally, **enemies spawn randomly** in different positions each time the game is played, increasing the unpredictability and replayability of the game. I also implemented the **Singleton pattern** to ensure that game state data, such as health and inventory, is maintained consistently between scenes, allowing for a smooth transition throughout the game.

## **Features**
- **Platformer Gameplay**: Classic platformer mechanics where the player moves through levels, overcoming obstacles and enemies.
- **Turn-Based Combat**: Players face enemies that randomly attack based on a dice roll algorithm.
- **Random Enemy Spawning**: Each time the game is played, enemies spawn at random positions on the map.
- **Singleton Pattern**: Ensures data consistency across scenes (player health, inventory, etc.).
- **Multiple Characters**: While multiple characters are available, all follow a single main character through the game.

## **Technologies Used**
- **Unity** (Game Engine)
- **C#** (Programming Language)

## **How to Play**
- Use **WASD** to move the player.
- Left-click to interact with enemies and items.
- The game is turn-based, with attacks occurring randomly based on dice rolls.
- Enemies will appear in random positions on each playthrough.
